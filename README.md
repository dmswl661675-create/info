# 행사 최종 인포 편집기 v3

## 기능
- 신간 2종 + 구간 2종
- 굿즈 자유 추가 / 삭제
- 표지 및 굿즈 이미지 교체
- 텍스트 직접 수정
- 선택한 텍스트의 폰트 / 볼드 / 기울기 / 색상 변경
- 파스텔 단색 배경 18종
- 사용자 지정 배경색
- 직접 배경 이미지 업로드
- 배경 이미지 맞춤 / 위치 설정
- SNS 영역 삭제
- PNG 저장
